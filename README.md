## ✈️ Airline Performance Analysis Dashboard

## 📌 Project Overview

This project presents an interactive Power BI dashboard developed to analyze airline performance and operational trends.

The dashboard provides insights into airline activity, passenger trends, flight performance, routes, delays, and other key business metrics.

The objective of this project is to transform airline data into meaningful visual insights that can support data-driven decision-making.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## 🎯 Project Objectives

- Analyze airline performance
- Understand passenger and flight trends
- Compare airline and route performance
- Identify patterns in flight delays
- Analyze trends over time
- Identify areas for operational improvement
